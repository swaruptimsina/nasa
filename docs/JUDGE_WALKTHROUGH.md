# Judge walkthrough and fallback plan

## Presenter framing

“Echoes of Rasuwa is for a community-preparedness educator. It helps them decide what evidence to request before discussing flood preparedness. It does not tell anyone when a mountain will fail or whether to evacuate.”

“Rasuwa's reported flood impacts motivate the problem. The real radar comparison is a separate, dated NASA NISAR example at Hubbard Glacier. The local Rasuwa terrain and radar are educational illustrations.”

## Deterministic clean-launch path

1. Launch locally and click START GUIDED EVIDENCE TRAIL. No audio, traversal or keyboard memorization is needed.
2. Problem: show the dated NDRRMA context link. Do not read casualty totals or assert climate attribution.
3. Observation: move the archived NISAR wipe from one acquisition to the other. Point out newly green patches and persistent green terrain. Explain NASA's rougher-surface / stronger-return interpretation. Do not quantify displacement or a hazard probability from RGB pixels.
4. Evidence: distinguish NASA-reported follow-up flights from our unverified local assets and fictional NPC dialogue. Open the asset review to demonstrate that unknown origin/date/permissions are visible rather than hidden.
5. Interpretation: return with Evidence trail / sources; open Rasuwa observatory. Compare scenario steps and select SHOW IN 3D. Explain the schematic slope–river–settlement relationship. Values are simulation, elevations illustration, not measured local science. Read the displayed relief and artistic LOS-to-height exaggeration; do not interpret the height warp as a vertical-motion measurement.
6. Possible action: return to the trail and open the hypothetical action simulator. Set the toy evidence-review threshold to 18 mm and planning effort to 75%. These are author-chosen game targets, not engineering advice. Acknowledge missing independent evidence. The completion button becomes available; completing it changes only the game. Export the educational worksheet and show its non-operational warning.
7. Limitations: finish with what is missing—calibrated local NISAR ingestion, independent field evidence, consent, uncertainty/quality masks and professional review. Expand provenance; show the exact official challenge link and candid eligibility hold.

## Suggested closing

“The distinctive part is the reasoning trail rather than a hazard-colored map: observe, question, seek evidence and discuss action. We have not validated a warning system or measured community impact. The next scientific milestone is a documented local NISAR product pair and independent corroboration.”

## Fallbacks

- External NASA APIs unavailable: keep the local server running. The verified NISAR browse pair is bundled locally. GIBS fails honestly; POWER local values are labeled illustration; EONET invents no events. The worksheet must retain these classifications.
- WebGL unavailable: use the 2D observatory and the same scenario-step buttons. Explain that 3D spatial presentation is optional, not additional measured science. No universal WebGL support is claimed.
- Slow network: the service timeout covers fetch and JSON parsing; the core guide does not wait for NASA telemetry. Fonts fall back to system monospace if Google Fonts is unavailable.
- Missing reference asset: use the linked NASA article and the explicit unavailable message. Do not replace a missing observation with a generated image.
- Live demo interrupted: reopen the localhost URL and restart the guide. Progress is in memory and deliberately not treated as scientific evidence.
- Do not claim a recording exists. Real local QA screenshots, if present, are in docs/qa/screenshots; they document limited checks, not a validated operational deployment.

## Before public presentation / submission

Obtain organizer guidance about pre-event work; verify registration and official challenge selection; confirm code license and image reuse rights; obtain local review of culture, names and translations; disclose AI assistance; verify the latest judging/submission guide. Do not describe prospective stakeholders as partners.
