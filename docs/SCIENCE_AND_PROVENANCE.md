# Science, claims and provenance review

Review date: 2026-11-10. This is a local prototype review, not NASA endorsement, an operational assessment, or a submission eligibility certificate.

## Central scientific boundary

The application imports two unchanged NASA-published NISAR browse images at Hubbard Glacier (2025-11-26 and 2025-12-08) and provides a visual comparison. NASA describes rougher debris-covered surfaces producing stronger returns, with some already-green surfaces unchanged.[8] This is **archived observation at browse level**, not our own calibrated backscatter/deformation analysis.

Rasuwa's reported avalanche/debris-flood event is a real motivation, described in NDRRMA's 2026-09-01 situation report and ICIMOD's knowledge portal.[11][10] Neither source makes the app's procedural layers into measured local NISAR products. No casualty total, displacement magnitude, deterministic precursor warning or achieved benefit is imported into the demo.

InSAR compares phase from multiple acquisitions. Phase effects from geometry, orbit, topography and surface consistency must be considered before interpreting motion.[9] Phase wrapping is not the same thing as decorrelation; a longer wavelength does not guarantee coherence. Our schematic color patterns are educational simulation, not evidence of a specific slope's behavior.

## Actual source trace / implementation notes

- `nasaEarthDataService.ts`: POWER fetch starts when atlas, observatory or action UI opens. Validates all four parameters for all monthly/annual entries; never fills missing fetched fields with zero and then labels them live. Successful response cache expires after five minutes; unsuccessful local examples are not cached as observations. Timeout and cleanup cover fetch plus JSON parsing.
- EONET fetch occurs on opening atlas. A successful empty Point list is not a fabricated fallback; unavailable service returns no events. The feed does not certify an absence of local hazards.
- GIBS is an image request from the observatory's NASA-context pane. Fixed-date archive and failure states are displayed. It is not an app-derived flood or NISAR layer.
- `regionalDemGenerator.ts`, `terrainHydrology.ts`, `TerrainMap3D.tsx`: procedural surfaces, animated patterns, geometric palettes and hard-coded scenario metrics. No granule/quality metadata, inversion, multi-sensor ingestion or quantitative validation. Animation progress is not physical event time.
- `ImpactInterventionModal.tsx`: arbitrary educational checklist; no hazard probability or operational engineering model. Export explicitly identifies missing field validation and prospective—not actual—partners.
